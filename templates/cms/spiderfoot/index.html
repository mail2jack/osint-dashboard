Quick Start

How to Use SpiderFoot

  1. Configure Connection: Go to Settings and enter your SpiderFoot server URL and credentials.
  2. Start a Scan: Click "Start New Scan" and enter a target (domain, email, IP address, etc.).
  3. Choose Profile: Select an investigation profile based on your needs.
  4. Link to Case: Optionally link the scan to a case for easy tracking.
  5. Import Results: Once complete, import findings directly into your case.

Target Types

  • DOMAIN_NAME: Websites, company domains (e.g., example.com)
  • EMAILADDR: Email addresses for person/breach investigations
  • IP_ADDRESS: IP addresses for infrastructure analysis
  • PHONE_NUMBER: Phone numbers for identity correlation
  • USERNAME: Social media/forum usernames
  • BITCOIN_ADDRESS: Cryptocurrency addresses for financial tracking
